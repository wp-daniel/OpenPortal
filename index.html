Storage

Choose your database

A single file holds accounts, groups and permissions. SQLite is the default for a portal running on one instance.

ConfigurationDatabase__Provider=Sqlite
Deployment guide

Multiple portal instances can share one database. The project’s Docker Compose file includes PostgreSQL and a dedicated migration step.

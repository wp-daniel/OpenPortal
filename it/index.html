Integrazioni

Collega le tue app

Aggiungi OpenPortal.Client alla tua applicazione ASP.NET Core. Approva l’app nel portale e scegli quali persone o gruppi possono accedere.

Estratto da Program.csbuilder.Services
.AddOpenPortalAuthentication(
builder.Configuration);
Guida all’integrazione

Sul tuo server, OpenPortal agisce da provider OpenID Connect. Registra il client, configura il redirect e usa il flusso Authorization Code con PKCE.

Discovery del providerGET
/.well-known/openid-configuration

Scegli il database

Un singolo file per gli account, i gruppi e i permessi. SQLite è la scelta predefinita per un portale con una sola istanza.

ConfigurazioneDatabase__Provider=Sqlite
Guida al deployment

Un database condiviso da più istanze del portale. Il file Docker Compose del progetto include PostgreSQL e un passaggio dedicato alle migrazioni.

ConfigurazioneDatabase__Provider=PostgreSql
